Connection Notes

  • Keep the Sensor ESP32, ESP32-CAM, and viewing computer or phone on the same local Wi-Fi network.
  • Enter only the correct local device URLs. The page automatically adds http:// if you enter only an IP address.
  • If an ESP32 webpage does not display inside the panel, select Open Tab. Some ESP32 firmware blocks iframe embedding.
  • Zoom changes the display scale of the webpage inside each monitoring panel.
